# Amogh Anakru — academic website

A minimal, content-first academic website for GitHub Pages. It uses plain HTML and CSS and has no build step, framework, external font, or JavaScript dependency.

## Files

- `index.html` — all public content
- `styles.css` — typography, layout, and responsive behavior
- `EDIT_ME.md` — exact editing instructions and blank drafting spaces
- `assets/headshot.jpg` — replace with a portrait
- `assets/Amogh_Anakru_CV.pdf` — downloadable CV
- `assets/favicon.svg` — browser icon

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages deployment

Create a repository named `USERNAME.github.io`, upload these files to the root of the `main` branch, and enable Pages under **Settings → Pages**.
